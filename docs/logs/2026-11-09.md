# 2026-11-09

## runTurn 收回 Loop

- **为什么**:0014 把 `ask` 移出内核后,CLI / REPL / web / smoke / 测试各有一份同构解析;
  改一次事件协议要追五处,web 那份已经是变体。
- **怎么改**:
  - `LoopRun` 增加 `runTurn({ text }, { onEvent? })`:生成 prompt id、先订阅再 `send`、
    按 `INBOX_TAKE` / `USER_MESSAGE` 对齐 turn、收集最后一步正文、错误归到这一轮;
  - 解析只放 `loop/live.ts`;`send` + `events` 保留为底层协议;
  - CLI / REPL 删掉 `_turn.ts`,smoke 直接调 `runTurn`;web 只保留「最终回答由 ANSWER 行渲染」
    的表现层裁剪,不再解析 turn;
  - 测试改用 `runTurn`,补「事件转发」与「`onEvent` 抛异常不挂死」两条用例。
- **代价**:`runTurn` 的等待策略(无超时、等 `TURN_END`、最后一步正文)成为内核默认;
  要自定义仍可绕过。详见 [`../decisions/0082-run-turn-on-loop.md`](../decisions/0082-run-turn-on-loop.md)。
- **验证**:`pnpm check` / `pnpm typecheck` / `pnpm test`(10 文件 92 用例)全绿;
  未跑真 key smoke(需要 vault 注入密钥)。

## runTurn 提到与 run 平级;transcript 按会话跨 run

- **为什么**:0082 把 `runTurn` 挂在 `run` 的句柄上,一次性调用仍要自己起 / 配 / 停 run;
  顶层 `runTurn` 每轮关 run 又会撞上 `ENGINE_START` 清 transcript 的旧规则,多轮记忆会丢。
- **怎么改**:
  - `LoopShape.runTurn(config, input, options?)`:内部 `run` → `configure` → 句柄 `runTurn` →
    `ensuring(Fiber.interrupt(fiber))`;句柄级 `runTurn` 保留(不关 run);
  - `ProjectionLive` 的 `ENGINE_START` 不再清 transcript;新增 `resetTranscript`,
    `ArchiveRuntime` 构建时调用(层实例 = 会话边界);
  - `Events` 增加 `begin`,`Loop.run` 在 fork 前清掉上一次 `ENGINE_END` 的回放;
  - CLI / REPL / smoke / web 都改成顶层 `Agent.runTurn`,不再自己持有常驻 session。
- **代价**:每轮一个 run(`ENGINE_START` / `ENGINE_END` 与调度成本);transcript 不跨层恢复;
  顶层 `onEvent` 看不到自己这轮的 `ENGINE_END`;浏览器断开现在会关掉本轮 run。
- **验证**:`pnpm check` / `pnpm typecheck` / `pnpm test`(10 文件 94 用例)/ `pnpm build` 全绿;
  新增「顶层 runTurn 每轮起停、transcript 跨 run」与「`resetTranscript`」用例。未跑真 key smoke。
