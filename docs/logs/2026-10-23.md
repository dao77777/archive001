# 2026-10-23

## Web 宿主改用 `effect/http`,dev 期改走 Vite 代理

- **为什么**:手写 `node:http` 的宿主把"安全闸 + API + 前端产物"揉在一个 `createServer` 里,
  且 handler 边界上要 `runtime.runPromise`,取消 / 依赖注入都用不上 Effect 的语义。
- **怎么改**(`packages/client/web/src/host/`):
  - `main.ts` 只做装配:`HttpRouter.serve` + `NodeHttpServer.layer` + `Layer.launch`;
  - `routes.ts` 三条路由(`state` / `turn` / `reset`)+ `/api/*` JSON 404;请求体由 `TurnBodySchema` 解析;
  - `session.ts` 新增 `Session` 服务:一套 `Agent` + 工具的**子 scope**,`reset` = 换一套;
    `turn` 用 `Stream.callback` 出事件流(浏览器断开即中断);
  - `guard.ts`:`Guard`(全局:回环 `Host` + 同源 `Origin`)+ `RequireToken`(turn / reset);
  - `_domain.ts` / `_util.ts`(纯判定,带 `_util.test.ts`)/ `_constants.ts` 不变。
- **dev 形态**:页面归 Vite(`pnpm web`),`/api/*` 由 `server.proxy` 转到 5180;
  宿主在 dev 只给 `/api/*`,prod(`NODE_ENV=production`)才 `HttpStaticServer` serve `dist/`。
- **顺带修掉**:旧版 prod 下 `serveStatic("/")` 直接吐 `dist/index.html`,从不种令牌 cookie,
  于是浏览器调 `/api/*` 全 401。新的握手是 `/api/state`(不要求令牌、响应里种 cookie)。
- **验证**:dev / prod 两种形态各跑一遍 —— 页面、静态资源、SPA 兜底、`/api/state`、
  真 key 的 `/api/turn`(含 `tool_call` / `tool_result` 多行 NDJSON)、`/api/reset` 后历史清空、
  跨站 `Origin` / 无令牌 → 401;Vite(5190)→ 代理 → 宿主(5180)整条链路通。
- **落档**:新增 [`../decisions/0007-effect-http-host.md`](../decisions/0007-effect-http-host.md),
  重写 [`../designs/client/web/host.md`](../designs/client/web/host.md),README 的 dev 命令同步。
