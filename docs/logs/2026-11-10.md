# 2026-11-10

## runTurn 独立成 Turn 服务;Agent 只留持续运行

- **为什么**:`run` 是持续运行(以 step 为循环),`runTurn` 是"起一个 run、跑一轮、关掉"的
  用例层;两种模式挤在一个服务里,句柄也跟着背上了"怎么解析一轮"的责任。
- **怎么改**:
  - 新增 `turn/`:`service.ts`(`TurnShape` + `Turn` + `TurnInput` / `TurnOptions`)、
    `live.ts`(`TurnLive` + `parseTurn`);
  - `Turn.runTurn(config, input, options?)` 借 `Loop.run` 起 run → `configure` →
    订阅 `events` / `send` / 等 `TURN_END` → `ensuring(Fiber.interrupt(fiber))`;
  - `LoopShape` 只剩 `run`;`LoopRun` 只剩 `events` / `fiber` / `send` / `configure`;
  - `AgentLive` 输出 `Loop | Turn`;SDK 导出 `Turn` / `TurnLive` / `TurnInput` / `TurnOptions` /
    `TurnShape`;
  - CLI / REPL / smoke / web 都改成 `yield* Turn` 后调 `turn.runTurn`;
  - 测试里的持续模式自己订阅事件(测试辅助 `ask`),`Turn.runTurn` 单独测。
- **两种模式**:`Turn.runTurn` 一次完整的 turn;`Agent.run` 持续运行、调用方自己 `send` /
  订阅 `events` / 决定何时停。持续模式没有解析助手。
- **代价**:多一个服务 Tag,自定义装配要 include `TurnLive`;`Agent` 不再有 `runTurn`(破坏性);
  `AgentLive` 的输出从 `Layer<Loop>` 变成 `Layer<Loop | Turn>`;顶层 `onEvent` 看不到自己这轮的
  `ENGINE_END`。
- **验证**:`pnpm check` / `pnpm typecheck` / `pnpm test`(10 文件 94 用例)/ `pnpm build` 全绿。

## Engine 只跑 step;Turn 用 archive hook 织入 turn

- **为什么**:0084 之后 `Turn` 独立了,但 `Engine` 还留着 `turnIdRef` / `startTurn` / `endTurn` /
  `failTurn`,以及 step 的 `parentId`;turn 是 step 的分组语义,不该在 step 循环里。
- **怎么改**:
  - `Engine` 只发 `STEP_START` / `STEP_END` / `STEP_ERROR` 与 step 内容,不再发 `TURN_*`,
    也不给 step 挂 `parentId`;无调用时只 `endStep`,不再 `endTurn`;
  - `Loop.run(options?: { archive?: EventHook })` 暴露 archive hook;`Events.publish` 写入前先过 hook,
    hook 可插入 / 改写 / 丢弃条目;
  - `Turn` 新增 `makeTurnHook()`:在 `STEP_START` 前插 `TURN_START`、给 step 挂 `parentId`;
    在无调用 / 出错的 `STEP_END` 后补 `TURN_ERROR` / `TURN_END`;引擎收尾时补开着的轮;
  - `Turn.runTurn` 调 `loop.run({ archive: makeTurnHook() })`;
  - 测试里的持续模式也挂 `makeTurnHook()`(测试辅助),`ask` 保持 old turn 对齐;
  - 新增「Engine 不挂 hook 时没有 TURN_*」用例。
- **代价**:不挂 hook 的 `run` 只有 `STEP_*`;turn 的事件顺序依赖 hook;hook 可以改写任意事件;
  `Loop.run` 从 `Effect` 变成函数(`run()` / `run({ archive })`)。
- **验证**:`pnpm check` / `pnpm typecheck` / `pnpm test`(10 文件 95 用例)/ `pnpm build` 全绿。

## archive 加入 session

- **为什么**:0083 的会话边界是层实例,一个 JSONL 文件里的多条会话无法区分、无法切回;
  reset / 新进程 / CLI 各自解释"新会话"。
- **怎么改**:
  - `SessionId`(branded)+ `ArchiveEntry.sessionId?`;旧文件归 `LEGACY_SESSION_ID`;
  - `Events.publish` 用 `Archive.currentSession` 打标;`Archive.append` 给缺省条目补当前会话;
  - `Archive` 新增 `currentSession` / `sessions` / `readSession` / `startSession` / `useSession`;
  - `Projection` 保留 `allEntries`,`setSession(id)` 按 session 重折;删掉 `resetTranscript`;
  - `ArchiveRuntime` 启动默认回到最后一段会话;web reset 换层后 `startSession`;CLI / smoke 先开新会话;
  - `AgentLive` 输出 `Agent | Turn | Archive`,客户端能直接用 Archive;
  - 测试:projection 按 session 隔离、`readSession` / `sessions` / `useSession` / `startSession`。
- **代价**:entry 多一个字段;投影多存 `allEntries`,切会话 O(会话条目数);会话元数据只有 id。
- **验证**:`pnpm check` / `pnpm typecheck` / `pnpm test`(10 文件 96 用例)/ `pnpm build` 全绿。

## Web 端会话列表

- **为什么**:archive 已经有 session,但浏览器只能看当前一段;没法切回去。
- **怎么改**:
  - 宿主 `Session` 增加 `sessions` / `current` / `open`;`/api/sessions` 列表,`/api/sessions/open` 切换并返回原始条目;
  - `/api/reset` 返回新 session id;
  - 浏览器 `useAgent` 开页读会话列表并打开当前会话(不再自动 reset);新增 `openSession` / `newSession`;
  - `blocksFromEntries` 把历史条目折回消息流(用户消息从 `INBOX_OFFER` 取,工具结果按 callId 回填);
  - 底栏加「会话」弹层:标题 / 条数 / 最后活动时间,当前会话反白;底部「新会话」。
- **代价**:会话标题取第一条用户消息(没有元数据);切换时重折历史条目;
  旧会话没有标题 / 删除 / 重命名。
- **验证**:宿主 `/api/sessions` / `/api/sessions/open` / `/api/reset` 实测;
  `pnpm check` / `pnpm typecheck` / `pnpm test`(11 文件 98 用例)/ `pnpm build` 全绿。
