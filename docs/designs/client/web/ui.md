# 设计:Web 客户端界面

> 代码在 `packages/client/web`。内核见 [`../../agent/loop.md`](../../agent/loop.md) / [`../../agent/llm.md`](../../agent/llm.md)。
> 美术参照(**仅风格**,含实测数据)见 [`style-references.md`](style-references.md) ——「科罗廖夫十字绽开」。
> ⚠️ **主题是档案,不是航天**:参照片只提供纸墨、细线、砖红、字号层级与暗场;**十字不进界面**。

## 美术方向

**近白纸 + 近黑墨 + 一枚砖红 + 1px 细线**;主体永远只有一个(卷宗夹),其余是等宽小字。
暗场只留一个用途:**思考中**。

**无一处闭合边框**:界面上所有线都两端淡出、或只画一小段 —— 线是辅助线与标记,不是框;
界限由留白、色块与字重表达。文字**只有中文与拉丁标识符**,不做双语装饰(不用西里尔字母)。

| 借自参照                                                                                  | 不借                                                                         |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 白色基底上交替暗场、细线 + 虚线疏密、红作标点、粗黑体大句、等宽贴角小字、"多线构一个主体" | 快切、位移缩放、半调照片与报纸拼贴、网格纸底纹、**航天题材(十字/火箭/年份)** |

## 排版

1. **无框、方角**:没有圆角,也没有一处闭合边框 —— 线条一律 `.hairline`(两端淡出)或一小段领线,
   并且有出口;框感只由留白与色块(墨块、暗带、纸白弹层)承担。
2. **等宽小标签**:`.label` = 10px / `letter-spacing .18em` / 大写,内容**中文单语**(拉丁只给标识符):
   `密钥已配置`、`档案 001`、`MODEL`。不做中俄并列 —— 参照是苏联题材,但界面不做双语装饰。
3. **细线**:1px `--color-rule`,只用于 `.hairline`(输入底线 / 领线 / 工具块顶线);
   **没有横贯全页的线**,也没有虚线边框(虚线只出现在卷宗夹的卡片上)。
4. **字号三层**:字标 30px、标题 36px(粗黑)、正文 13–14px、标签 10px;**没有中间层**。
5. **彩色只有一个红,且只表示状态**:

   | 槽位               | 语义       | 形态                     |
   | ------------------ | ---------- | ------------------------ |
   | 错误块             | 出错了     | 2px 左线 + 红字          |
   | 头部「未配置密钥」 | 需要你动手 | 红小字                   |
   | 思考暗带           | 正在发生   | 顶部 2px 红线 + 红色计时 |
   | 下拉当前项         | 当前值     | 红 `▪`                   |
   | `第 00N 轮`        | 仪表读数   | 红色衬线数字             |

   三条限制:① 同屏最多两处;② 面积 ≤2%(2px 线,或 ≤12px 的一小段字);
   ③ 不用作品牌色、按钮主色、气泡底色 —— 参照里红从不铺面。

6. **暗场一处**:只有「思考中」是黑底 + 卷宗夹;其余全亮。
7. **控件不带标签**:没有 `MODEL` / `THINKING` 这类说明文字 —— 模型与档位只靠**字色、字号、
   字距、大小写、可点形态**区分(表见「布局」);需要报身份时用 `aria-label`,不给眼睛看。
   输入下沿的标注 10–12px、`muted`、无框,空间不够就截断状态文字,**不换行**。
8. **卡片无框**:答复 / 工具 / 思维链都不画边框 —— 层次用三种手段给:
   标签前一段 16px 领线、工具块顶部一条淡出发丝线、左側 2px 红(仅错误)。

## 主体:卷宗夹(`folder-mark.tsx`)

主题是**档案**,主体就是档案的载体:一只卷宗夹,里面一张卡片正被抽出一点。

- 夹子外轮廓 1px(左上一段凸起 = 标签位,里面有档号线与装订孔);
- 卡片 0.8px,微歪 1.4°(手插进去的卡不会正),卡上两条实线 + 一条虚线(疏密对比);
- 线条只有实线 / 虚线两种,没有填充、没有阴影描边;
- **空态**:300px,`ink/45`(细线在近白底上要压淡),6s 呼吸 + 卡片 7s 抽出/落回;
- **思考中**:124px,近白 `paper`,加一层极淡的 `drop-shadow` 当发光 —— **只有暗带里才允许发光**;
- 题材与风格分开记:风格借自 `style-references.md` 的参照片,**航天题材一律不进界面**。

## 布局

```
╷  四角裁切标记(在角上留缺口,不围成框)                    ╵
                消息流(max-w-76ch 居中;顶边淡出收口)
                空态 = 卷宗夹 + 启封 + 等待第一条记录(没 key 时多一句指路)
                思考中 = 暗带 + 发光卷宗 + 计时

  说点什么 · enter 发送 / shift+enter 换行
  ───────────────────────────────── 输入底线(两端淡出),聚焦变墨
  就绪 · 第 000 轮   设置 宿主未配置密钥  deepseek-flash ▽  HIGH  ← 宿主缺 key 时
  就绪 · 第 000 轮   设置                  deepseek-flash ▽  HIGH  ← 正常时
```

- **空态只说两件事**:大字 `启封`、一行 `等待第一条记录`;再根据宿主状态补一行 ——
  `工具目录 · <cwd>`(正常)/ `宿主没有密钥:启动时设置 DEEPSEEK_API_KEY` / `连不上本地宿主`;
- **设置弹层取消了**:密钥改由宿主从环境变量读,浏览器侧没有任何要填的密钥;
- **四周没有框**:只有四角"裁切标记"(每个角两道短线,故意在角上留 8px 缺口)——
  它提示"这是一张纸的边界",而不把界面围成一张截图;
- **没有顶栏,也没有标题**:页面不自报家门 —— 名字在浏览器标签页(`<title>archive001</title>`)
  与空态右缘的竖排 `档案 001` 里。页面上**一条横贯线都没有**;消息流的顶边用淡出遮罩
  (`mask-image`)收口,滚动时内容淡进纸里,不靠线去挡切边;
- **底栏不画分隔线**:输入区与消息流靠留白分开 —— 输入自家的底线已经在位置上,再加一条只是重
  复同一件事(试过,删掉后底栏反而安静);
- **输入区下沿两端**:两端的对齐参照是**输入框自己的宽度范围**(`max-w-76ch`),不是页面四角。
  左端只报状态(`就绪 / 思考中 · 第 N 轮`),右端是**密钥状态 + 设置 ｜ 模型 + 档位**:
  - **只有"宿主缺密钥"才显示**:红字 `宿主未配置密钥`(密钥在宿主那侧,浏览器里没有可填的地方);
    宿主配好后这个位置**一个字都没有**;
  - **红只给状态文字,按钮不上色**:`设置` 永远是中性幽灵字,抢眼的是"未配置"这件事,不是按钮;
  - **没有清空按钮**:刷新页面即新会话(挂载时会 POST `/api/reset` 清掉宿主里的历史)——
    少一个可点的对象,也少一个能误触的操作;
  - **模型 + 档位是一组**(本次会话的两个参数),**分组只用间距**:组内 12px,组外 40px。
    不加竖线、不加括号、不加底色 —— 线会让这一行想抢眼,而这行本来就该是最安静的;
    读屏上用 `role="group"` + `aria-label="会话参数"` 把语义分组补上;
  - **模型** `deepseek-flash ▽`:点开是一个只列已知型号的小菜单(向上弹)。**只能选不能打** ——
    写错的型号不会在本地报错,只会在请求时变成 400;旧持久化里的未知型号不丢,原样保留并排最前;
  - **档位** `LOW`:**点一下就切**(off → low → high → max → off),没有菜单。

  两个参数都不带标签,靠四重对比分开:

  |             | 模型             | 档位              |
  | ----------- | ---------------- | ----------------- |
  | 字色        | 墨 `ink`         | 灰 `muted`        |
  | 字号 / 字距 | 12px,常规(宽松)  | 10px,疏排 `.18em` |
  | 大小写      | 原样小写(标识符) | 大写              |
  | 可点形态    | `▽` 下拉         | 无箭头,点即切     |

  两者都无框底色,**hover / 聚焦才浮出 1px 底线**;可访问性靠这条线与 `aria-label`,不靠标签文字。

- **输入框单行起步**(28px),内容变多就向上撑高,上限 180px 之后内部滚动;
  **回车直接发送**,`shift+enter` 换行 —— 所以不放发送按钮,少一个可点的对象;
  输入区没有框,只有一条两端淡出的底线(聚焦这条线变墨);
- **思考中是唯一的暗场**:整条 190px 高的黑底横带,中央是发光的卷宗夹(卡片反复抽出),两角是
  `思考中` 与 `MM:SS` 计时 —— 参照里主体本就只出现在暗场,所以这里才用黑。
- **设置是弹层**(Base UI `Dialog`):无边框,纸白 + 阴影 + 顶部一条淡出发丝线。
  里面**没有输入框**:四行只读说明(宿主 / 工具目录 / 密钥 / 模型档位在哪切)+ 底部的
  「清空会话」(界面清块 + 宿主重开运行时)与「关闭」。

| 元素     | 样式                                                                  |
| -------- | --------------------------------------------------------------------- |
| 提问     | 右对齐 · 等宽 12.5px 墨字 · **右侧 1px 墨线**,不填充                  |
| 答复     | 无框:领线 + `答复` 标签 + 正文                                        |
| 思维链   | 无框 `<details>`,默认收起,等宽小字                                    |
| 工具     | 顶部淡出发丝线 + 等宽字,运行中只显示 `…`                              |
| 错误     | 左侧 2px 红线 + 红字(不填底)                                          |
| 输入下沿 | 左端状态 / 右端 设置 + 密钥状态 + 模型 + 档位 · 10–12px · 无框,无标签 |

## 密钥

- 存 `localStorage` 的 `archive001.web.key`(与普通设置分开,便于一键清除);刷新、重开都在。
- 没 key 时:紧挨「设置」的状态字变红(红只表示"需要你动手"),按钮本身不变色;
  输入框照常可用、只是发不出去;占位符始终只讲**怎么输入**,不拿它当"去填 key"的告示牌。
- 明文存放,弹层里写明风险;公共电脑上用「清除 key」。
- 只在**缺 key** 时于输入框下沿「设置」旁显示红字「未配置密钥」;配好之后不显示任何字样
  (没有"已配置"这种常态播报),也从不回显片段。
- 模型 / 档位存 `archive001.web.settings`(与 key 分开):换模型、点档位都会立刻写回,刷新不丢;
  实测见 `docs/logs/2026-10-21.md`。
