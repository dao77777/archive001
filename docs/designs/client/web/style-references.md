# 美术参照(仅风格):科罗廖夫十字绽开

> 来源:`~/Code/_asset/media-online/video-bilibili/科罗廖夫十字绽开-卡门线上化作花束-航天史填词/video.mp4`
> 不入 git。本文是**度量 + 拆解**;落地到界面见 [`ui.md`](ui.md)。数字都可按文末命令复现。
>
> ⚠️ **只借风格,不借题材。** 本项目的主题是**档案**(卷宗、卡片、编号、归档),不是航天;
> 影片里的火箭尾焰十字**不进入界面**,只作为"多条 1px 细线构成一个几何主体"的手法样本。

## 0. 一句话

**近白纸 + 近黑场交替、1px 细线、唯一一枚砖红;主体永远只有一个(插画 / 图纸 / 器物),其余全是等宽小字。**
界面只借它:纸与墨、红作为标点、细线的疏密对比、极端的字号层级、以及"多线构一个主体"的手法 ——
不借它的题材(火箭尾焰十字)、不借它的快切与拼贴。

## 1. 事实

| 项            | 值                                                                                  |
| ------------- | ----------------------------------------------------------------------------------- |
| 分辨率 / 帧率 | 852×480 / 30fps                                                                     |
| 时长 / 码率   | 151s / ≈0.45 Mbps                                                                   |
| 镜头          | 28 个,平均 5.39s,硬切 10 次,运动指数 3.94                                           |
| **平均帧差**  | **20.42**(2fps 采样;对比:静态排版片约 1)**                                          |
| 明暗分布      | 抽样 76 帧:亮场(>180)36、中间 34、暗场(<60)6,平均亮度 170 → **以亮为主,暗场是插曲** |
| 声音          | LUFS −9.6 / LRA 5.2(响、动态小)                                                     |

**读法**:它不是"暗调科技风",而是**白纸基底上不断插进黑色的画面**;十字那种发光感只出现在暗场里。

## 2. 色彩(实测)

| 角色         | 值                                               | 用途                                           |
| ------------ | ------------------------------------------------ | ---------------------------------------------- |
| 亮场底       | `#fbfaf9`                                        | 主背景(近白、微暖)                             |
| 暗场底       | `#0e0e0e` / `#292828`                            | 十字与发光画面                                 |
| 中灰         | `#c8c4c3` / `#625958`                            | 网格纸、半调照片、分隔                         |
| 墨 / 字      | `#000`–`#141414`                                 | 歌词、标题                                     |
| **唯一彩色** | 红:`#a02b30`(最饱和 10% 的均值),混合后 `#9b4348` | **只做三种事**:强调词、仪表数字、横线 / 小方块 |
| 红面积       | 4.6%(t=30s 单帧统计)                             | 可撑起一整句,但从不铺满                        |

## 3. 字体

| 类           | 特征                 | 用途                                   |
| ------------ | -------------------- | -------------------------------------- |
| 粗黑体(紧缩) | 极粗、行距紧、可反白 | 大句/歌词,常占满画面宽度               |
| 粗衬线数字   | 重、方、无装饰       | 1948、100、"100 公里"                  |
| 等宽小字     | 大写、疏排、贴边角   | 时间戳(UTC 19:31:36)、坐标、日期、水印 |

层级只有三级:**一句巨大的话 > 一个数字 > 一行元数据**。没有中间层,所以画面总是"空且满"。

## 4. 构图

- **一屏一主体**:插画、照片、技术图纸、地图任选其一,不并置;
- **贴边标注**:小字永远在四角或竖排贴边;
- **网格纸 / 坐标纸**当底纹(浅灰线),给"工程"的质感,但不抢主体;
- **明暗交替**用来分段:一段亮、一段暗,而不是靠装饰分区;
- 黑白半调照片、报纸剪贴只在需要"史料感"时出现。

## 5. 参考片主体的构造(只学手法,不搬题材)

从中心向四个方向绽开的尾焰,抽象成三层(这是**影片**的构法;界面不画这个十字):

| 层   | 几何                                | 作用             |
| ---- | ----------------------------------- | ---------------- |
| 主轴 | 4 条压扁椭圆(0°/90°/180°/270°)      | 构成十字的骨架   |
| 轨道 | 4 条虚线椭圆(45° 偏移,`1.5 4` 疏密) | 制造"绽开"的层次 |
| 尾焰 | 4 条自中心射出的直线                | 指向性           |

线宽 ≤1px。发光感来自**叠加**而不是阴影:同一形状用低透明度描两三遍,或用 `drop-shadow` 极淡一层。

## 6. 运动

| 现象            | 数据                 | 可用在界面上的部分              |
| --------------- | -------------------- | ------------------------------- |
| 快切(5.4s 一镜) | 帧差 20.4            | ❌ 聊天界面需要稳定可读         |
| 硬切 + 叠化     | 10 次硬切 / 其余叠化 | ⚠️ 只借"叠化"做状态切换         |
| 主体缓慢呼吸    | —                    | ✅ 思考指示器(卷宗夹里抽出卡片) |
| 插画位移/缩放   | 高运动指数           | ❌ 干扰阅读                     |

## 7. 可移植的语法(以及本项目采不采)

| 语法                             | 采用    | 说明                                         |
| -------------------------------- | ------- | -------------------------------------------- |
| 近白纸底 `#fbfaf9`               | ✅      | 取代原来的灰纸;长文阅读更清爽                |
| 近黑墨 `#141414`                 | ✅      | 正文与反白块                                 |
| 唯一砖红 `#a02b30`               | ✅      | 只出现在错误 / 强调 / 极少量标注             |
| 1px 细线 + 疏密对比(实线 / 虚线) | ✅      | 辅助线、领线、输入底线                       |
| 粗黑体大句                       | ✅      | 字标与标题(系统 sans,紧字距)                 |
| 粗衬线数字                       | ⚠️ 限量 | 只用于计数(`第 001 轮`)这类"仪表数字"        |
| 等宽大写小标签                   | ✅      | 密钥状态、`LOW` 档位(不再给控件挂标签)       |
| 贴角 / 竖排标注                  | ✅      | 空态右缘竖排、输入框下沿两端                 |
| 明暗交替                         | ✅      | **思考中**用一条暗带 + 发光卷宗              |
| 十字几何                         | ❌      | 题材是航天;只学"多条 1px 线构一个主体"的手法 |
| 发光 / bloom                     | ⚠️ 克制 | 只在暗带的卷宗上;亮场不用                    |
| 半调照片 / 报纸剪贴 / 网格纸     | ❌      | 与"工具界面"气质冲突,只在将来做档案页时考虑  |
| 快切 / 位移 / 缩放               | ❌      | 阅读稳定性优先                               |

## 9. 复现

```bash
K=~/Code/_asset/media-online/video-bilibili/科罗廖夫十字绽开-卡门线上化作花束-航天史填词/video.mp4

# 事实
ffprobe -v error -show_entries format=duration,bit_rate -show_entries stream=width,height,r_frame_rate -of default=noprint_wrappers=1 "$K"

# 主色
ffmpeg -v error -i "$K" -vf "palettegen=max_colors=6" -y /tmp/p.png

# 明暗分布(2fps 灰度,统计均值)
ffmpeg -v error -i "$K" -vf "fps=1/2,scale=160:-1" -f rawvideo -pix_fmt gray /tmp/g.raw

# 红:扫 rgb,取 r-g>40 的最饱和 10%
ffmpeg -v error -ss 30 -i "$K" -frames:v 1 -f rawvideo -pix_fmt rgb24 - | <脚本>

# 镜头与节奏
ffmpeg -v error -i "$K" -vf "select='gt(scene,0.22)',showinfo" -f null -
```
